# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful. Technical disagreement — including blunt disagreement about design — is welcome and expected. Personal attacks, harassment, and bad-faith participation are not.

Report unacceptable behavior privately to the maintainers via GitHub. Reports are handled confidentially. Maintainers may warn, temporarily block, or permanently ban participants whose behavior violates this code.

The full text, including enforcement guidelines, is at the link above.
